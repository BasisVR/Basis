# Basis Steam Transport

This package is the staging area for the Steam lobby and Steam transport patch.

Goals:
- Keep the existing LiteNetLib implementation working as-is.
- Add Steam as an additional transport option.
- Reuse Basis resource loading for worlds and props.
- Keep new code isolated so repo-wide churn stays low.

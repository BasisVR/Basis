Each example is a whole script with the scene setup it needs. They build on each other: start with **Basics** if you are new to Basis scripting, then **Synced Toggle** for your first networked script.

| Example | Shows |
| --- | --- |
| [Basics](/en/docs/scripting/examples/basics) | A Cilbox script, inspector fields, `Update`, a UI button. |
| [Synced Toggle](/en/docs/scripting/examples/synced-toggle) | A button that turns something on or off for everyone, including late joiners. |
| [Scoreboard](/en/docs/scripting/examples/scoreboard) | A synced score kept by one owner, with other players asking the owner to add points. |
| [Pickup Gun](/en/docs/scripting/examples/pickup-gun) | A synced pickup that fires, with the shot shown to everyone. |
| [Touch Button](/en/docs/scripting/examples/touch-button) | Pressing a button with your finger in VR. |
| [Seats](/en/docs/scripting/examples/seats) | Seating, turning and ejecting players from a script. |
| [Zones and Teleporters](/en/docs/scripting/examples/zones-and-teleporters) | Detecting the local player in an area, teleporting, trampolines and lobby counts. |
| [NPC Follow](/en/docs/scripting/examples/npc-follow) | A NavMesh agent simulated by one owner and sent to everyone. |
| [Image Loading](/en/docs/scripting/examples/image-loading) | Showing a picture from a URL on a sign. |
| [Minimap](/en/docs/scripting/examples/minimap) | A top down camera following the local player onto a render texture. |
| [Persistence](/en/docs/scripting/examples/persistence) | Saving and loading a player's progress. |
| [Settings Tab](/en/docs/scripting/examples/settings-tab) | Adding world options to the player's menu. |
| [Day Night Cycle](/en/docs/scripting/examples/day-night-cycle) | A sun on the shared server clock, no networking needed. |
| [Round Timer](/en/docs/scripting/examples/round-timer) | A synced countdown from one message per round. |
| [Trivia Quiz](/en/docs/scripting/examples/trivia-quiz) | Questions from a JSON file with the current question synced. |
| [Server Best Time](/en/docs/scripting/examples/server-best-time) | Per player saves on the server with `BasisServerStorageShim`. |
| [Staff Door](/en/docs/scripting/examples/staff-door) | A door for admins and moderators that updates live. |
| [Voice Stage](/en/docs/scripting/examples/voice-stage) | Playing a speaker's voice from stage speakers. |
| [Drawing Board](/en/docs/scripting/examples/drawing-board) | A shared whiteboard with compressed late joiner snapshots. |
| [Random Loot](/en/docs/scripting/examples/random-loot) | The same random item for everyone with no messages. |
| [Elevator](/en/docs/scripting/examples/elevator) | A shared moving platform from one synced number. |
| [Tail Reaction](/en/docs/scripting/examples/tail-reaction) | An avatar reacting when its jiggle bones are grabbed. |
| [Hand Flashlight](/en/docs/scripting/examples/hand-flashlight) | Pinning an object to the hand without lag. |
| [Desktop and VR Input](/en/docs/scripting/examples/desktop-and-vr-input) | One script for mouse clicks and VR triggers. |
| [Localized Sign](/en/docs/scripting/examples/localized-sign) | Text in the player's language. |
| [Performance Scaler](/en/docs/scripting/examples/performance-scaler) | Cutting effects when the frame rate drops. |
| [Server Portal](/en/docs/scripting/examples/server-portal) | Sending players to another server. |
| [Boids](/en/docs/scripting/examples/boids) | 200 birds animated with one batched call per frame. |

All examples are also in the Unity editor under **Basis > Creator Guide**, where each code block has a copy button.
